# Simple Bash Utils — `cat` & `grep`

Практический проект на C: разработка собственных версий Unix/Linux-утилит `cat` и `grep`.

## Что реализовано

- консольные программы на C11;
- работа с аргументами командной строки;
- реализация основных флагов `cat`;
- реализация основных флагов `grep`;
- регулярные выражения через POSIX regex;
- поддержка комбинаций флагов;
- сборка через `Makefile`;
- интеграционные тесты со сравнением поведения с системными утилитами;
- структурированное программирование и переиспользование общего кода.

## Технологии

`C11` · `GCC` · `Makefile` · `POSIX` · `Regex` · `Bash` · `Linux`

## Структура

- `src/cat/` — реализация `s21_cat`;
- `src/grep/` — реализация `s21_grep`;
- `src/` — исходный код и тесты.

## Сборка

```bash
make s21_cat
make s21_grep
```

## Для портфолио

Проект демонстрирует навыки системного программирования на C, работы с Linux CLI, Makefile, регулярными выражениями и тестированием консольных приложений.
